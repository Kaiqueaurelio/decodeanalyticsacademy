# Decode Analytics Academy

Plataforma acadêmica para Ciência da Computação, Sistemas de Informação e Engenharia de Computação.

## Ambiente de Desenvolvimento

### Requisitos
- Node.js 22.x
- Bun 1.x

### Instalação
```bash
bun install
```

### Execução
```bash
bun dev
```

## Segurança e Auditoria

O projeto passa por auditorias regulares de segurança.
Não utilize credenciais hardcoded no código ou em scripts de teste.
Utilize variáveis de ambiente (`.env`) para chaves e segredos.
